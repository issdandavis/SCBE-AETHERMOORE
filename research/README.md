# research/

Research notes, simulations, and benchmark records. Exploratory work; nothing here is part of the shipped pipeline.

| Folder | Contents |
|--------|----------|
| `benchmarks/` | Benchmarking reference, the "Corridor Test" design, a score template, and result records under `results/` |
| `comms_sim/` | Simulations of agent coordination under communication delay (Mars DTN lockstep, squad autonomy, delayed code generation) |
| `eml_simulator/` | Script that re-runs the EML / T-cell identities as executable checks |
| `sat_comparison/` | Measured comparison of the pure-Python minimal-core search against OR-Tools CP-SAT |
| `aether-manifold/` | Notes on a fluidic computer concept and on rotations and hyperbolic rotations |
| `materials/` | Materials research briefs with an evidence table |
| `mtef-cell/` | The M-TEF (magneto-triboelectric fluid) cell project: architecture, prototypes, draft bill of materials, a small model with tests. Has its own README and an all-rights-reserved license |
| `marketing/` | A zero-budget marketing playbook |

Result JSON files record single runs. Treat physical-device material under `mtef-cell/` as unbuilt proposals unless a file states measured data.

---

Every file in this directory is listed with a one-line description in [`docs/file-index/research.md`](../docs/file-index/research.md).
