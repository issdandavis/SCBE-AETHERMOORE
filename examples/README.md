# examples/

Example code and sample inputs.

| Path | Contents |
|------|----------|
| `python/basic_firewall.py` | Smallest working SCBE firewall example; start here |
| `aethermoore*.py` and other root-level `.py` files | Reference implementations and constant demos moved out of the repo root |
| `SCBEAgent/` | Amazon Bedrock AgentCore agent exposing SCBE |
| `MyAgent/`, `TestAgent/` | AgentCore scaffolds. `TestAgent/src/main.py` is empty, and all three `test/test_main.py` files are entirely commented out |
| `npm/` | Fleet definitions and use-case scenarios for the npm package. Has its own README |
| `geoseal/` | GeoSeal task YAML examples |
| `stvm/` | An STVM v0 assembly example |
| `workflows/` | A repo-health-check workflow definition |

---

Every file in this directory is listed with a one-line description in [`docs/file-index/examples.md`](../docs/file-index/examples.md).
