# notebooks/

Jupyter notebooks (31) and Python scripts (7), mostly Colab and Kaggle training runs: the "Brick" continual-learning series, QLoRA fine-tunes, and the SCBE systems-coder notebook.

The six `build_*_nb.py` files generate notebooks (for example `build_scbe_systems_coder_nb.py` writes `scbe_systems_coder_colab.ipynb`); for those, edit the builder, not the notebook. `scripts/system/build_ai_training_run_ledger.py` scans `*.ipynb` here to build the training-run ledger.

---

Every file in this directory is listed with a one-line description in [`docs/file-index/notebooks.md`](../docs/file-index/notebooks.md).
