# Spiral staircase reasoning benchmark

Status: pre-registered before the full matrix.

## Question

Can one shared recurrent transition cell enter nested reversible realms, retain
the state at every landing, and return through the same doors at depths never
seen during training? Does an exact inverse receipt support that behavior? Does
a bounded golden-angle/phi coordinate add anything beyond matched ordinary,
zero, uniform, and shuffled controls?

The staircase is a recursive control-flow test. It does not claim open-domain
reasoning. Every target is generated by an exact six-bit reversible operation.

## Structure

- State: one byte in the range 0..63, represented through six separate Sacred
  Tongue surfaces or an equal-width control representation.
- Realms: modular addition, XOR, and six-bit rotation.
- OPEN: apply a reversible action and enter the next landing.
- CLOSE: apply the inverse action and return one landing.
- Receipt arm: CLOSE receives the inverse action and realm.
- No-receipt arm: CLOSE receives only a close marker. It must retain the action
  stack inside its recurrent hidden state.
- One GRU cell is reused at every landing. Trainable parameter count is equal
  for every arm.
- Training depths: 1..4. Held-out depths: 5..12.

The phi schedule is a bounded event coordinate: golden-angle sine/cosine pairs,
a decaying phi shell, and a bounded height. It enters the learned event encoder;
it never changes a target or performs an operation for the model.

## Arms

1. aligned codec + receipt + phi schedule
2. aligned codec + no close receipt + phi schedule
3. aligned codec + receipt + uniform schedule
4. aligned codec + receipt + zero schedule
5. aligned codec + receipt + depth-shuffled phi schedule
6. ordinary exact bytes + receipt + phi schedule
7. lane-shuffled codec + receipt + phi schedule

## Gates fixed before running

All effect claims require the paired effect to be positive for every seed and
the mean effect to exceed two pooled standard deviations.

- Receipt support: aligned receipt beats aligned no-receipt on deep route floor.
- Phi support: aligned phi beats uniform, zero, and shuffled-phi on deep route
  floor.
- Tokenizer-specific support: aligned beats both ordinary exact bytes and the
  shuffled-codec control on deep route floor.
- Absolute deep nesting: every aligned-receipt-phi seed reaches at least 0.90
  deep route floor and 0.70 full-route exact over depths 5..12.

Three seeds are required. Exact same-seed replay, inverse-operation checks,
complete nested return checks, codec round trips, finite gradients, and equal
parameter counts must pass before the matrix can run.
