## Main dataflow

```text
read-only state/action generator
  -> 37-field state + deterministic action + view/sector/group identity
  -> immutable 30,000-row arm banks
  -> matched standard MLP (37 -> 64 -> 64 -> 5)
  -> initial / best / final checkpoint states
  -> held-sector + anchor predictions
  -> stable-class metrics + weight/gradient receipts
  -> independent verifier + stratified gate
  -> NO_SELECTION or bounded research candidate
```

The deterministic execution path remains separate:

```text
bounded input
  -> canonical action token
  -> immutable compiler row
  -> finite geometry gate
  -> deterministic executor
  -> execution-grounded speech receipt
```

The overnight learned experiments propose routes or data recipes; they do not
replace this compiler path or gain permission to execute actions.

## What changed in weights and outputs

### Reproducible narrow gain

The six-seed frozen adapter is the cleanest learned result.  Giving the adapter
real input identity changed outputs on source-disjoint coding examples while
the equal-size null adapter learned nothing and the parent stayed bit-identical.
Absolute coding accuracy is still only about 3.5%, so this proves input access,
not a capable coding model.

### Data-support gain

In the completed hash-specificity campaign, random multi-view data reached
`0.9035` held accuracy and `0.7696` stable F1 versus `0.8302` and `0.7064` for
static unique data.  It won all 15 matched comparisons on both metrics.  Its
weights also moved farther (`14.5786` total drift) and improved the weak
action-3 output.  Because random was a control, this is the hypothesis now
being confirmed, not a selected checkpoint.

### Useful negative results

- Exact repetition did not substitute for additional legal views.
- Forcing all three views of one latent action state into one gradient unit did
  not help; views are partly action-equivariant rather than same-label copies.
- Elite-gradient coherence reached roughly `0.97--0.997` but did not beat
  ordinary orbit controls.
- Semantic factor balancing increased measured cell uniformity and gradient
  agreement but reduced transfer and anchor retention.
- Shuffled-factor and factor-free hash spreading were effectively tied; their
  structure did not explain the gain.

These closures are progress because they prevent more compute from being spent
on the wrong mechanism.

## Remaining gap to the system goal

The work moved Clay closer to a controlled action learner, but the complete
goal still requires a bridge from these measured data rules into an
input-visible Clay descendant that retains the deterministic compiler fallback.
Natural image/audio/language material, token-level action compilation, the
14-layer runtime, and end-to-end throughput were not improved by this night.

Next legitimate order:

1. finish the active random-multiview confirmation;
2. independently replay outcomes and exact exposure/support receipts;
3. keep `NO_SELECTION` if any sector/control gate misses;
4. only then preregister a frozen-input-adapter run using the confirmed data
   recipe and the existing deterministic compiler boundary;
5. do not add another selector, scheduler, or geometry layer before that test.
