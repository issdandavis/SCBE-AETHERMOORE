What this folder is

A single consolidated write-up of one long working session that started with the history of computational thinking and ended with a testable design for a multi-venue exchange aggregator whose decision log feeds SCBE. The through-line: every ledger — tape, memory cell, order book, blockchain, dollar bill — is a record of state that only means something if it persists, can be read back, and can be reconciled against another record.

The original session artifacts (artifacts/*.md, artifacts/scbe_reconciliation_stubs.py) did not persist on the working box. These files are the durable reconstruction.
