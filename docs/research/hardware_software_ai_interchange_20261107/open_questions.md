# Open Questions: Hardware–Software–AI Interchange

Status: unresolved research and build queue
Date: 2026-11-07

## Highest-Priority Questions

1. What is the smallest operation vocabulary that can be expressed identically
   in software, a simulator, and one non-electronic substrate without hiding
   substrate-specific behavior?
2. Which route fields are hard constraints, which are measured objectives, and
   which may be learned preferences?
3. Can a W3C-PROV-compatible token envelope remain compact enough for streaming
   retrieval without copying full source content?
4. Does preserving mixture order and source bundles improve claim verification
   over a size-matched flat embedding or ordinary evidence-set baseline?
5. When support and contradiction coexist, should the top-level trit remain zero
   until a declared resolution rule fires, or should multiple issue-specific
   trits be exposed?
6. Can activation control use token-margin feedback to recover behavior that
   equal-norm geometric steering moved internally but did not express at output?
7. What minimum source-disjoint prospective set can test the six-view catalog
   without reusing session material already present in v6?
8. How should private conversation sources be summarized so useful design intent
   survives while credentials, personal data, and copyrighted text do not?

## Hardware Questions

- Which demonstrator is commercially sensible: microfluidic controller,
  nanofluidic memory emulator, FPGA transducer, or sensor-routing board?
- What units, calibration curves, endurance, error rates, and conversion losses
  must each physical adapter report?
- Do fluid/ionic paths offer a net benefit only when the payload is already
  chemical or biological?
- Can backside routing and heterogeneous tiers inform the software router's
  topology without pretending chip-floorplan distance equals semantic distance?
- Is cavitation controllable enough for a repeatable state element, or should it
  remain an excluded metaphor until bench evidence exists?

## Software and Product Questions

- Should the interchange contract be a Python dataclass/JSON Schema first, then
  TypeScript, or an MLIR dialect from the start?
- Which existing SCBE router owns eligibility, and which owns preference?
- How are adapters versioned so an npm and PyPI release execute the same contract?
- What conformance fixture proves installation, one useful workflow, deterministic
  replay, upgrade safety, and failure behavior?
- Which package is the product: capability registry, evidence router, receipt
  verifier, or a bundled control plane?

## AI and Discernment Questions

- Does the model need a learned gate, or can deterministic eligibility plus a
  zero-parameter distance heuristic match it?
- What evidence probes are independent enough to act like distinct chemical
  reagents rather than correlated restatements?
- How are fact, opinion, forecast, command, preference, and normative claim types
  represented before assigning an evidence trit?
- Can confidence be calibrated under source shift and adversarial rhetoric?
- What abstention policy maximizes selective accuracy without making the system
  useless?
- How do we distinguish a source's stance from the system's evidence verdict?

## Stop Conditions

- Stop if exact source identity or rights cannot be carried through the route.
- Stop if units or operation semantics are implicit.
- Stop if a learned preference can bypass a hard policy or compatibility gate.
- Stop if correlated views are counted as independent evidence.
- Stop if evaluation shares source records or normalized token streams with
  training/development material.
- Stop local model training while C: free space remains below 5 GiB.
- Do not promote an adapter or activation layer without multi-seed evidence over
  both baseline and size-matched control at the declared uncertainty gate.
