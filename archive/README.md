# archive/

Retired code and artifacts kept for reference. **Nothing here is imported by the live packages or run by CI.** Most subfolders carry a `WHY_HERE.md` recording when and why the content was moved.

| Folder | Contents |
|--------|----------|
| `demos/` | Demo scripts moved out of the root `demos/` folder |
| `ui-graveyard/` | Three superseded UI roots (`aetherbrowse/`, `app/`, `ui/`) retired in the 2026-04 GeoShell consolidation |
| `root_capture_cleanup/2026-04-22/` | Reports and plots that had accumulated in the repo root |
| `public-pages/` | Old landing pages |
| `experimental/` | The "21D max" experimental module and a multimodal training scaffold |
| `manuscripts/` | Plain-text manuscript of *The Six Tongues Protocol* |
| `data-snapshots/` | One Notion export snapshot (not strict JSON) |
| `test-install/` | Minimal npm project (`package.json` and lockfile only) |

If you need something from here, copy it out into the owning package rather than importing from `archive/`.

---

Every file in this directory is listed with a one-line description in [`docs/file-index/archive.md`](../docs/file-index/archive.md).
