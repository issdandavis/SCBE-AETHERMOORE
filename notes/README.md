# notes/

An Obsidian vault of working notes. Not authoritative documentation; canonical specs are in `docs/`.

| Folder | Contents |
|--------|----------|
| `sphere-grid/` | Skill-tree notes: one folder per Sacred Tongue (`KO-Command`, `AV-Transport`, `RU-Entropy`, `CA-Compute`, `UM-Security`, `DR-Structure`), each with four tiers |
| `round-table/` | Multi-agent discussion records |
| `System/` | System notes |
| `theory/` | Mathematical and theoretical notes |
| `manhwa-project/` | Comic project ledger and references |
| `sessions/` | Session logs |
| `agent-memory/`, `user-guides/`, `federal/`, `archive/` | Smaller collections |

`scripts/system/review_system_and_notes.py` and `scripts/system/research_training_bridge.py` read `.md` files from this vault recursively.

---

Every file in this directory is listed with a one-line description in [`docs/file-index/notes.md`](../docs/file-index/notes.md).
