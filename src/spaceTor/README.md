# src/spaceTor/

SpaceTor routing in TypeScript: `space-tor-router.ts` (3D spatial pathfinding), `trust-manager.ts` (trust scoring with Langues weighting), `hybrid-crypto.ts` (hybrid encryption layer), and `combat-network.ts` (redundancy manager). Tests are in `tests/spaceTor/`.
