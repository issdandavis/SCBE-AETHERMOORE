# src/mcp/

Model Context Protocol servers in Python: `scbe_govern_mcp.py` (governed action tools), `scbe_verify_mcp.py` (offline verification tools), `scbe_universal_mcp.py` (universal backend port), and `context_broker_mcp.py` (context broker). The TypeScript MCP server is in `src/mcp_server/`.
