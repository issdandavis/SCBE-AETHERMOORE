## Description

pip is simple until a machine has two Python installations, a stale virtual
environment, a native extension, or a deployment that must work without the
internet.

This practical guide starts with interpreter identity and follows the complete
terminal workflow: virtual environments, installs, upgrades, requirements,
constraints, dependency groups, PEP 723 scripts, experimental lock files,
wheels, offline wheelhouses, hash-checked installs, package audits, project
builds, and repair commands.

The examples cover PowerShell, Windows Command Prompt, bash, and zsh. They were
checked against Python 3.12.10 and pip 26.2.2, with dated references to the
official pip, Python, PyPA, Wheel, build, Twine, pipx, pip-tools, virtualenv,
pip-audit, and KDP documentation.
