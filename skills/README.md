# skills/

Agent skills. Each folder is one skill with a `SKILL.md` (front-matter `name` and `description`, then instructions) and optional `references/`, `scripts/`, and `agents/` subfolders.

There are 22 skills here, covering training operations (`scbe-colab-training-ops`, `scbe-research-training-bridge`), document and storage management, government contract intelligence, Stripe integration (`stripe-best-practices`, `upgrade-stripe`, `stripe-projects`), browser operations, and codebase orientation (`scbe-codebase-orienter`). `codex-mirror/` mirrors selected local Codex skills into the repo (see its README).

The file index lists every skill with the description from its own front-matter. Skills used by Claude Code in this repo are under `.claude/skills/`.
