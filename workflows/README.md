# workflows/

Workflow definitions for external orchestrators. These are not GitHub Actions; those are in `.github/workflows/`.

- `n8n/` — 20 n8n workflow exports and supporting files.
- `tenreary/`, `momentum/`, `scbe_ai_kernel/`, `openai/` — workflow definitions for other runners.

Most of these JSON files have no description field; the file index lists their top-level keys.

---

Every file in this directory is listed with a one-line description in [`docs/file-index/workflows.md`](../docs/file-index/workflows.md).
