# api/

Two different things share this directory. Read this before adding code.

1. **A Python FastAPI app** (`main.py`, `auth.py`, `metering.py`, `persistence.py`, `validation.py`, `audit_export.py`, and the `billing/`, `keys/`, `darpa_prep/`, `github_app/` packages). This is the *separate, non-canonical* API app. The canonical FastAPI app is `src/api/main.py`.
2. **Vercel serverless functions in JavaScript** (`_*.js` helpers plus `agent/` and `polly/`). These are the live lightweight agent bridge and the Polly chat/commerce endpoints.

| Path | What it is |
|------|------------|
| `agent/` | Vercel functions: static page servers, agent task endpoints, and the generated `router.js` |
| `polly/` | Vercel functions for Polly chat, catalog and commerce |
| `billing/` | SQLAlchemy + Stripe-SDK billing stack. **Not live** — placeholder price IDs. Kept because `auth.py` and `keys/` import its DB models and rate-limit tiers |
| `billing/stripe_webhook.js` | The live Vercel Stripe webhook (independent JS, pinned Payment Link IDs) |
| `keys/` | API key generation and hashing |
| `darpa_prep/` | SAM.gov / DARPA proposal-intelligence endpoints |
| `github_app/` | GitHub App webhook handling for the FastAPI lane |
| `governance-schema.yaml` | OpenAPI description of the governance API |

**Money path:** new checkout or subscription logic belongs in `src/api/stripe_billing.py` or as a Payment Link in `docs/offers.json`, never in `api/billing/routes.py`. See the "Canonical Money Path" section of the root `CLAUDE.md`.

`agent/router.js` and `polly/router.js` are regenerated by `scripts/vercel/generate-router.cjs`; do not edit them by hand.
