# spaces/

Hugging Face Spaces applications.

- `redteam/` — "SCBE Red Team Sandbox": a Gradio app for testing a prompt against the pipeline.
- `scbe-chat/` — "SCBE Polly Space": a FastAPI chat proxy, with Dockerfile.
- `polly-proxy/` — only a `requirements.txt`; the application file is not in this repository.
