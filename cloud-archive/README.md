# cloud-archive/

A frozen export of a Google Cloud Vertex AI notebook workspace, dated 2026-01-27.

`gcp-vertex-notebook-2026-01-27/prompt-data/<id>/` holds saved Vertex prompts as raw JSON-in-text files (`prompt_text*.txt`, `prompt_system_instruction*.txt`). Two of the prompt files are about 4 MB each.

Reference material only. Nothing reads these files.

---

Every file in this directory is listed with a one-line description in [`docs/file-index/cloud-archive.md`](../docs/file-index/cloud-archive.md).
