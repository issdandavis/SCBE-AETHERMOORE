# book/

Source for the technical book *AI Governance Fundamentals*.

`ai-governance-fundamentals/` holds `book.yaml` (title, authors, license, chapter order) and four chapters: the harmonic wall (bounded safety score), the four-tier risk decision, decision records, and Sacred Tongues as governance dimensions.

`book.yaml` uses the `scbe_runnable_ebook_v1` schema; `scripts/book/extract_chapter_examples.py` extracts the runnable code examples from a chapter. Fiction manuscripts are under `content/book/`.

Every file in this directory is listed with a one-line description in [`docs/file-index/book.md`](../docs/file-index/book.md).
