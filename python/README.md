# python/

The newer Python package tree, separate from `src/`.

| Package | What it is |
|---------|------------|
| `scbe/` | The main `scbe` Python module (139 files): governance through geometry, the AI browser, atomic tokenization, tongue roles |
| `helm/` | "Helm", the operator loop: AI runs the reversible work, humans approve the gates |
| `pqc/` | Post-quantum cryptography code. Its `__init__.py` has no docstring |
| `loom/` | "Loom", a small loop machine that emits one program in many languages |
| `inscribe/` | Compact numerics for agentic code work |
| `crank/` | "Crank", which turns long AI work into a visible workflow machine |
| `codeforge/` | The assembled workflow: intent in, verified code out |

**Import caution:** `src/` also contains Python packages, and there are two `symphonic_cipher` packages with different formulas (root and `src/`). See the root `CLAUDE.md` before writing imports.
