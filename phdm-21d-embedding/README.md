# phdm-21d-embedding/

One script: `scripts/upload_model_artifacts.py`, which uploads PHDM (Polyhedral Hamiltonian Defense Manifold) 21-dimensional embedding model artifacts to a Hugging Face model repository.

The PHDM implementation is `src/harmonic/phdm.ts`, published as the `scbe-aethermoore/phdm` export.
