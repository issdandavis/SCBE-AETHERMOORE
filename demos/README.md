# demos/

Runnable demonstrations.

| Path | What it shows |
|------|---------------|
| `reversible_board.py` | A reversible-board instruction set, offered as evidence for the bijective core |
| `toroidal_braid.py` | The toroidal braid extension of the same board (cyclic core) |
| `governance-gate/` | Client-side live demo of the governance gate; no backend. Has its own README |
| `gemma4_scbe_governance/` | Gemma model wrapped by SCBE governance: CLI demo, logic module, example benign and adversarial prompts. Has its own README |
| `aethermon/` | Browser game demo |
| `site-demos/` | Static customer demo pages |

`demo/` (singular) is a separate directory with its own README. Retired demos are in `archive/demos/`.

---

Every file in this directory is listed with a one-line description in [`docs/file-index/demos.md`](../docs/file-index/demos.md).
