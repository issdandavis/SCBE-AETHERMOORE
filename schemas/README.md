# schemas/

JSON Schema definitions.

- Root — agent action maps, endurance regimen, taskset, and run-report schemas, and others.
- `kernel-v1/` — request and response schemas for the SCBE Kernel v1 HTTP API (for example `GET /audit/{decision_id}`), plus the error shape.
- `swle/` — schemas for the SWLE multilingual lexicon dataset (entry rows and manifest).
- `examples/` — example documents that validate against the root schemas.

Every file in this directory is listed with a one-line description in [`docs/file-index/schemas.md`](../docs/file-index/schemas.md).
