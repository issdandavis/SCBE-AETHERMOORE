# physics_sim/

Small Python physics simulation package with SCBE input validation.

- `core.py` — the simulation core.
- `patrol.py` — "patrol/wall" validation of inputs before they reach the core.
- `test_*.py` — tests that live beside the code (run with `python -m pytest physics_sim/`).

A second copy of this package name exists at `src/physics_sim/`; check which one you are importing.
